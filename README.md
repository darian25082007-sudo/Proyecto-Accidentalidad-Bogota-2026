# Análisis de incidentes viales en Bogotá 2026

## Descripción
Aplicación desarrollada para analizar los incidentes viales registrados en Bogotá durante el primer semestre de 2026.

## Pregunta de investigación
¿Cómo se distribuyen los incidentes viales registrados en Bogotá según la hora, la localidad y el tipo de incidente?

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Funcionalidades
- Carga de archivos CSV.
- Limpieza y preparación de datos.
- Filtros por fechas y horas.
- Estadísticas descriptivas.
- Visualización de incidentes por hora.
- Análisis por localidad.
- Distribución por tipo de incidente.

## Periodo de estudio
1 de enero al 30 de junio de 2026.

## Ejecución
Instalar las dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar la aplicación:

```bash
streamlit run app.py
```
